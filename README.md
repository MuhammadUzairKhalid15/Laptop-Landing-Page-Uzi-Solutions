# Laptop Product Landing Page (HTML & CSS)

A product landing page for a laptop, built with HTML & CSS. It has a header with logo, navigation, and cart icon, a bold headline with call-to-action buttons, an animated laptop image, and soft decorative circles in the background.

> Note: this is a front-end design only. The buttons, cart, and slider controls are visual and do not work yet. Images are used for practice purposes only.

🔗 **Live Demo:** https://muhammaduzairkhalid15.github.io/Laptop-Landing-Page-Uzi-Solutions/
💻 **Repository:** https://github.com/MuhammadUzairKhalid15/Laptop-Landing-Page-Uzi-Solutions

## ✨ Features

- 🧭 Header with logo, three nav links with a hover color, and a cart icon
- 💻 Large laptop image that drops in with a CSS animation and a soft shadow
- 🔤 Gradient-colored headline text using `background-clip: text`
- 🔘 Two buttons with opposite hover effects (outline and filled)
- 🟣 Decorative circle shapes behind the content
- 📱 Responsive layout with a breakpoint at 1024px (content stacks vertically)

## 🔧 Built With

- **HTML5**
- **CSS3** – flexbox, keyframe animation, gradients, media queries
- **Google Fonts** – Poppins

   ```
   git clone https://github.com/MuhammadUzairKhalid15/Laptop-Landing-Page-Uzi-Solutions.git
   ```
2. Open `index.html` in your browser. No build steps needed.

## 💡 What I Practiced

- Laying out a header and hero section with flexbox
- Creating a drop-in animation with `@keyframes`
- Making gradient text with `-webkit-background-clip: text`
- Positioning decorative SVG shapes behind content with `position: absolute` and `z-index`
- Writing a media query to stack the layout on smaller screens
